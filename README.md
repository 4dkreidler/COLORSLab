# COLORSLab
Description: 
The COLORS application is designed to allow a user to log in to a website and then allow them to add colors that can be searched after being added. 

Technologies used: 
The technologies used is a LAMP stack that can be bought on DigitalOcean that can be setup to allow website activities. 

Setup: 
To setup a LAMP stack to run the COLORS application you would need to first purchase your own LAMP stack from Digital Ocean. After making the purchase, you need to setup the mysql so that you have a database that can be populated with two tables, one for users to log in to the website and one to store the colors added by a user. Once a database is setup in the mysql you can add the files from this github to directories in the LAMP stack.

How to use: 
Once setup up has been complete, you can go to your website's domain address with a web browser and enter a username and password to login in. After logging in, you can enter a color of you choice and press add to add the color. After a color has been added with that user account, you can then search for that color and it should display that color's name.
